写文章时自动分析正文，按 SEO 思路生成候选标签，由你勾选决定是否采用。

由 **西瓜烧鱼** 开发 · 网站：https://www.rrshare.com/

== 功能 ==

* 在文章编辑页右侧加一个「SEO 自动标签」面板（兼容区块编辑器与经典编辑器）
* 点一下按钮，插件读当前正文内容，给出候选标签
* 每个标签带勾选框，**你勾选哪几个，才用哪几个**；不点「应用」就不会写进文章
* 两种生成方式：
  - 本地算法：不联网、不花钱、装上即用。靠中文词组频次 + 标题加权 + 已有标签匹配挑词
  - AI 智能：填一个 OpenAI 兼容接口的 API Key，让大模型按 SEO 价值选词，效果更好
* 优先复用站内已有标签，避免同一个意思建出一堆标签（对 SEO 更友好）
* 已有标签会打上「站内已有」标记
* **文章列表页多一列「SEO 标签」**：一眼看出哪篇文章还没打标签，可一键生成补齐
* **标签健康度面板**：统计没打标签的文章数、没被使用的标签数、只用过 1 次的标签数，并给出收敛建议
* **标签数量提醒**：一篇文章超过 8 个标签时提示可能稀释权重
* **AI 结果缓存**：同一篇文章内容不变时重复点生成不再花钱
* **调用限速**：可设每用户每小时最多调几次 AI，防止有人刷爆你的 API 额度
* **调用失败会说明原因**：Key 无效 / 余额不足 / 被限流 / 地址写错，都直接告诉你，不会只说「失败了」
* **本月调用次数统计**：设置页能看到这个月调了几次 AI
* **标签屏蔽词**：写进黑名单的词永远不会被推荐

== 为什么标签要控制数量 ==

WordPress 的每个标签都会生成一个归档页。标签建得太多太碎，会：
* 产出大量内容稀薄的页面，稀释整站权重
* 让同一个意思被拆成多个标签（如「PS 教程」和「Photoshop 教程」），互相分权

所以本插件默认只给 5 个候选，并且默认优先复用已有标签。

== AI 兼容性 ==

不同服务商的返回格式不完全一样，插件会按常见格式逐个兜底，避免换个服务商就「读不懂」：

* 标准 OpenAI 兼容：`choices[0].message.content`
* 老式 completions：`choices[0].text`
* 多模态数组：`message.content[0].text`
* 部分网关：`output.text` / `content`
* 网关强制返回 SSE 分块时，会自动拼接

出错时会把 HTTP 状态码翻译成能照着修的建议，例如：

* `401` → API Key 无效或已过期，重新复制粘贴一次
* `402` → 账户余额不足，去服务商后台充值
* `404` → 接口地址不对，多数服务商要求以 /v1 结尾
* `429` → 被服务商限流了，等一会儿再试
* 超时 → 服务器可能出不了外网，或模型响应太慢

报错信息里的 API Key 会被自动脱敏，不会跟着错误提示泄露出去。

== 安装 ==

1. 后台 → 插件 → 安装插件 → 上传插件 → 选择 zip 文件 → 现在安装
2. 启用插件
3. 设置 → SEO 自动标签，按需配置

== 使用 ==

方式一（写文章时）：
1. 新建或编辑一篇文章
2. 右侧找到「SEO 自动标签」面板
3. 点「生成标签」
4. 勾选想用的（默认全选，可以取消）
5. 点「应用选中标签」
6. 保存文章

方式二（补旧文章）：
1. 到「文章」列表页
2. 看「SEO 标签」列，找到「未打标签」的文章
3. 点该行的「一键生成」
4. 确认弹窗里列出的标签后，自动追加进文章（不会删掉原有标签）

== AI 模式配置 ==

选「AI 智能」后填三样：服务商、API Key、模型名。
接口地址和模型名选服务商时会自动填好。

支持任何 OpenAI 兼容接口，内置预置：
* DeepSeek（推荐，中文好且便宜）
* 通义千问
* 智谱 GLM
* 月之暗面 Kimi
* OpenAI

填好后点「测试连接」确认能通，再去文章里用。

== 安全说明 ==

* 所有 AJAX 接口都校验 nonce 与用户权限
* AI 接口地址强制 https，并禁止指向内网 / 本机地址（防 SSRF）；
  保存与测试时还会做一次 DNS 解析检查，防止域名解析到内网 IP
* 单次最多创建 12 个标签，防止批量滥用
* 可配置每用户每小时的 AI 调用上限；超限自动降级到本地算法，不会报错中断
* 接口请求超时 25 秒，避免慢请求占满小内存机器的 PHP 进程池

== 消耗说明（AI 模式）==

会真实调用接口的地方只有四处：

* 编辑器点「生成标签」—— 一次调用；同一篇文章内容不变时读缓存，不重复计费
* 打开编辑器自动生成（可选开关）—— 同上
* 文章列表页「一键生成」—— 每篇一次调用
* 设置页「测试连接」—— 每次约 20 token，已限制一分钟最多 5 次

发送量控制：正文做「头 + 尾」采样，控制在 4000 字以内（约 2400 token），
单次调用成本约几厘钱。想更省就把「结果缓存」开着。

== 隐私 ==

* 本地算法模式：不向任何外部服务器发送数据
* AI 模式：仅在你点击「生成标签」时，把文章标题与正文（采样后 4000 字以内）
  发送到你自己配置的 API 地址
* 插件本身不收集、不上传任何数据到第三方
